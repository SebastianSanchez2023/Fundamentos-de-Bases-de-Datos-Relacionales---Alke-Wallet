## 📌 Descripción del Proyecto
Este repositorio contiene el diseño, modelado e implementación SQL para la base de datos relacional de **Alke Wallet**, una solución para la gestión de fondos financieros, transacciones entre usuarios y soporte multimoneda, cumpliendo con las 5 lecciones del módulo y los principios de normalización (3FN) y transaccionalidad (ACID).

---

## 📁 Estructura del Repositorio
- AlkeWallet.sql: Script SQL completo con creación de base de datos, DDL (tablas, claves primarias, foráneas, checks, índices), DML (datos de prueba), transacciones ACID y consultas DQL requeridas.
- Entrega_Modulo5_Alke_Wallet_Bases_De_Datos_Sebastian_Sanchez.doc: Documento oficial de entrega en formato Word listo para adjuntar con capturas y marco teórico.
- Entrega_Modulo5_Alke_Wallet_Bases_De_Datos_Sebastian_Sanchez.zip: Paquete comprimido para subir a la plataforma evaluativa.

---

## 🚀 Instrucciones de Ejecución
1. Abrir **SQLOnline** (modo MySQL 8 / MariaDB) o su gestor local preferido (MySQL Workbench / DBeaver / VS Code SQLTools).
2. Ejecutar el archivo AlkeWallet.sql en su totalidad.
3. Consultar las tablas generadas (moneda, usuario, 	ransaccion) y verificar las consultas del libro mayor.
